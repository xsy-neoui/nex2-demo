# 常见错误与排查指引
|问题表现|常见原因|排查建议|
|----|----|----|
|单击 AI 优化按钮无反应|事件未正确绑定到目标字段|检查 labelAfter 配置及 onClick 事件是否指向正确字段 API 名称|
|弹窗未打开或打开空白|devPageKey 或 URL 配置错误|确认页面代码已上传并启用，devPageKey 与自定义页面一致|
|回填字段无变化|回填逻辑未正确执行或字段 API 名称错误|检查 master.setFormData\(\{字段名:值\}\) 是否使用正确字段 API 名称，确保弹窗 onOk 回调触发|
|弹窗或接口异常|异步接口调用失败或返回空值|查看接口返回数据，增加日志调试，确保 retData?.data?.keyword 存在|
|多次单击按钮导致覆盖数据|弹窗回填逻辑未加条件|在回填前增加非空判断或数据比对，避免重复覆盖|
