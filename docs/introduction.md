# 前言

本文档旨在为开发人员提供页面扩展开发的相关指导，通过一些示例，帮助您了解通过 NEX 2.0 进行页面扩展的方法。

## 适用对象

本文档适用于具有一定前端开发经验的技术人员，特别是熟悉 HTML、CSS 和 JavaScript 的开发者。此外，文档默认读者已了解 NEX 2.0 的基本概念、工具准备和基本开发方法，以及 PaaS 平台其他功能的基础知识。如您不熟悉这些内容，请先参考以下资料进行学习：

-   [新版NEX2.0页面扩展开发手册](https://doc.xiaoshouyi.com/?sso-domain=login.xiaoshouyi.com#/proMan/workplaceDetail?url=%2F%2Fconcepts%2FnewNex20Dev_overview.html&id=1381&dir=output_1750841237852&time=1752636808539&proId=975&checkStat=undefined)
-   **文档中心** &gt; **产品手册** &gt; **PaaS 平台**下相关功能的介绍文档。

## 环境准备

在使用 NEX 2.0 进行扩展开发之前，必须先安装 **NEX 2.0 开发工具**。有关工具的获取与安装方法，请参考[使用介绍](https://doc.xiaoshouyi.com/?sso-domain=login.xiaoshouyi.com#/proMan/workplaceDetail?url=%2F%2Fconcepts%2FnewNex20Dev_usageInstructions.html&id=1454&dir=output_1760522890818&time=1760593393185&proId=1027&checkStat=undefined)中的**环境准备**。
