# 常见错误与排查指引
|问题表现|常见原因|排查建议|
|----|----|----|
|保存表单时校验未触发|beforeSave 事件未正确绑定|检查扩展脚本中是否正确使用beforeSave 事件绑定保存逻辑|
|单击保存后子表数量为 0 的数据仍被提交|beforeSave 未正确获取子表新增或更新记录|检查 details\[0\].create.concat\(details\[0\].update\) 是否覆盖所有子表记录，并确保正确引用子表 API 名称|
|子表金额合计校验不生效|汇总逻辑中未正确读取数量或单价字段，或字段 API 名称错误|确认循环计算 recordTotal = quantity\_\_c \* unitPrice\_\_c 是否使用正确字段 API 名称，并确保字段值为数字类型|
|校验失败时提示信息未显示|ctx.ui.noticeSuccess/noticeError 调用位置错误，或未正确返回 false|确认校验失败时函数返回 false，并在提示后中断保存流程|
|保存操作始终被阻止|校验逻辑条件判断有误|调试 beforeSave 函数，打印子表数量、金额及总金额，确认逻辑判断是否正确|
|子表金额合计超过总金额未提示|子表金额求和或主表总金额字段读取逻辑错误|打印调试求和过程，确认金额字段和总金额字段值正确获取|
|保存按钮单击无反应|beforeSave 返回值未正确设置|确认校验逻辑中 return true/false 正确控制保存流程|
|提示信息不清晰，用户无法理解错误原因|提示文案不明确或未覆盖所有校验场景|优化提示文案，明确说明是数量为 0 还是金额超限等，避免模糊错误信息|
|子表动态增删改未触发校验|未监听子表变动事件或变动后未重新计算|在子表增删改事件中触发校验函数，保持校验结果实时更新|
