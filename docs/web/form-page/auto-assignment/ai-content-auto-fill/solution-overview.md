# 方案介绍

## 方案概述

本方案通过在表单页面（EntityForm）中进行组件级扩展实现。在字段级别使用扩展属性，为目标字段追加操作按钮，并通过事件绑定实现按钮的交互逻辑。

## 扩展组件

|终端|扩展对象|扩展页面|扩展区域|扩展组件|扩展功能|
|---|----|----|----|----|----|
|网页端/移动端|合同申请单|表单页|主表单|合同摘要字段|新增“AI 优化”按钮，并执行内容优化逻辑|

## 功能设计

1.  **按钮设计**

    在合同摘要字段旁增加新按钮**AI 优化**。

2.  **按钮交互逻辑**

    当用户单击**AI 优化**按钮时，获取合同摘要字段内容，在弹出的页面中显示优化结果，用户单击确定后，可以自动回填并覆盖原有内容。

    1.  当用户单击**AI 优化**按钮时，系统获取“合同摘要”字段的当前内容，并在弹出的页面中展示 AI 生成的优化结果。
    2.  用户在查看优化结果后，单击“确定”按钮，即可将优化后的内容自动回填至原字段中，覆盖原有内容。

        !!! note

            本案例在实现过程中模拟了 AI 接口返回的优化内容，实际应用中可根据业务需求接入真实的 AI 接口，以实现自动生成与回填优化结果的完整功能。

## 使用的 NEX 扩展能力

   | 功能点 | 扩展能力类别 | 属性/函数/事件 | 说明 | 示例值/使用方式 |
   | --- | --- | --- | --- | --- |
   | 在**合同摘要**字段旁增加**AI优化**按钮 | 附加组件 | 属性：labelAfter | 在字段旁增加自定义按钮 | labelAfter: \{ type: 'button', label: 'AI优化' \} |
   | 设置按钮显示在字段下方 | 展示位置 | 属性：buttonLocation | 控制按钮相对于字段输入框的位置 | buttonLocation: 'bottom' |
   | 设置按钮样式，蓝色背景、白色文字、小尺寸圆角样式 | 组件样式 | 属性：label、style（内嵌于 labelAfter） | 控制按钮外观，如文字、颜色、尺寸、圆角 | ```javascript type: 'button', label: 'AI优化', style: { borderRadius: '28px', marginTop: '5px', background: '#0564f5', color: 'white' } ``` |
   | 单击按钮触发 AI 接口调用并展示优化结果弹窗 | 事件绑定 | 事件：onClick | 定义按钮单击后的行为逻辑，可调用接口或执行函数 | onClick: \(e\) =&gt; \{...\} |
