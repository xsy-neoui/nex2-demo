# 前提条件
以下前提条件仅为案例演示所需，实际请以您系统中的具体配置为准。

系统中必须存在下表所示的对象及相应字段

| 对象名称 | API 名称 | 字段类型 | 字段名称 | API 名称 | 其他说明 |
| --- | --- | --- | --- | --- | --- |
| 采购申请单 | purchaseRequest | 自动编号 | 申请单编号 | name | <p>编号格式：PR-{YYYY}-{MM}-{0000}</p><p>主属性字段</p> |
|  |  | 关联关系 | 申请人 | applicant | <p>关联标准对象：用户</p><p>默认值：当前登录用户</p><p>必填</p> |
|  |  | 日期 | 申请日期 | applyDate | <p>默认值：当前日期（TODAY()）</p><p>必填</p> |
|  |  | 货币 | 总预算金额 | totalBudget | <p>小数位数：0</p><p>必填</p> |
| 采购明细项 | purchaseItem | 文本 | 采购明细项名称 | name | 主属性字段 |
|  |  | 主子明细 | 采购申请单 | purchaseRequest | 主对象：采购申请单 |
|  |  | 关联关系 | 产品名称 | productNam | <p>关联标准对象：产品</p><p>必填</p> |
|  |  | 整数 | 数量 | quantity | 必填 |
|  |  | 货币 | 单价 | unitPrice | <p>小数位数：0</p><p>必填</p> |
|  |  | 计算-货币 | 金额 | totalAmount | <p>计算公式：数量 * 单价</p><p>小数位数：0</p> |
