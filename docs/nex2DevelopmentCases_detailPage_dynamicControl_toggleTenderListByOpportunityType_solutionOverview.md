# 方案介绍

## 方案概述

本方案通过在详情页（EntityDetail）中进行组件级扩展实现。通过扩展详情页加载逻辑，在页面初始化时获取商机类型字段值，并根据类型动态控制招标相关列表的显示或隐藏。当商机类型为“招标商机”时，显示招标相关信息；当类型为“非招标商机”时，则隐藏相关的招标信息模块，从而实现页面内容的差异化展示。

## 扩展组件

!!! note

    移动端相关列表摘要中的按钮暂不支持动态扩展，本案例仅适用于网页端。

|终端|扩展对象|扩展页面|扩展区域|扩展组件|扩展功能|
|---|----|----|----|----|----|
|网页端|自定义商机|详情页|相关列表|相关列表|根据商机类型，动态控制相关列表中关联对象（招标信息）的显示|

## 功能设计

1.  **触发时机**

    当详情页渲染完成后，执行权限判定逻辑。

2.  **数据获取**

    获取商机类型字段的值，用于判断是否为“招标商机”。

3.  **逻辑判定**

    当商机类型字段值为“招标商机”时，相关列表中显示“招标信息”。

    当商机类型字段值为“非招标商机”时，相关列表中隐藏“招标信息”。
