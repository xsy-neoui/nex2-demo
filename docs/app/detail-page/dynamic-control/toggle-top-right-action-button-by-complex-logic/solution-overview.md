# 方案介绍

## 方案概述

本方案通过在详情页（EntityDetail）中进行组件级扩展实现。通过扩展详情页的操作按钮逻辑，在页面加载时获取当前用户的职能信息职能及合同负责人字段，并根据预设条件动态控制右上角操作按钮（“编辑”、“删除”）的显示与隐藏。该方案可实现基于字段与用户属性的多维度权限控制，确保操作权限与业务规则一致，提升系统的安全性与使用体验。

## 扩展组件

|终端|扩展对象|扩展页面|扩展区域|扩展组件|扩展功能|
|---|----|----|----|----|----|
|网页端/移动端|签约合同|详情页|页面头部|头部按钮|在页面渲染后，根据用户职能和数据属性进行判断，动态控制“编辑”和“删除”按钮的显示|

## 功能设计

1.  **触发时机**

    当详情页渲染完成后，执行权限判定逻辑。

2.  **数据获取**
    -   获取当前登录用户的职能信息（主要职能）。
    -   获取当前合同记录的关键字段值（负责人、合同金额、合同状态）。
3.  **逻辑判定**
    -   **编辑按钮控制**

        仅当当前登录用户为合同负责人，且合同状态为“草稿”，并且合同金额 ≤ 500 万元时，显示“编辑”按钮。否则，隐藏“编辑”按钮。

    -   **删除按钮控制**

        仅当当前登录用户的主要职能为“默认管理员”时，显示“删除”按钮。否则，隐藏“删除”按钮。
