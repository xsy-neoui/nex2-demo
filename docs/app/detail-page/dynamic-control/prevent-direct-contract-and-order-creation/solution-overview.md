# 方案介绍

## 方案概述

本方案通过在详情页（EntityDetail）进行组件级扩展实现。在相关列表（relatedList）级别使用扩展属性，动态控制“新增”按钮的显示。通过事件绑定和权限判定逻辑，能够根据业务条件动态显示按钮，从而确保业务流程的合规性和操作的可控性。

## 扩展组件

|终端|扩展对象|扩展页面|扩展区域|扩展组件|扩展功能|
|---|----|----|----|----|----|
|网页端/移动端|自定义销售机会|详情页|相关列表|明细操作按钮|在页面渲染完成后，动态获取限制配置，并根据配置内容控制“新增”按钮的显示|

## 功能设计

1.  **触发时机**

    当详情页渲染完成后，执行权限判定逻辑。

2.  **限制配置获取**

    通过自定义对象存储限制配置，动态读取限制项，并根据这些限制控制销售机会详情页相关列表中“订单”和“合同”新增按钮的显示状态。


    | 控制项 | 控制项名称 | 说明 |
    | --- | --- | --- |
    | 启用状态 | enabled | 是否启用限制内容 - true/1：启用 - false/0：禁用 仅当启用时，限制配置才会生效 |
    | 默认管理员受限 | defaultAdminRestricted | 默认管理员是否受此限制 - true/1：受限制 - false/0：不受限制 |
    | 相关对象类型 | relatedType | 隐藏“新增”按钮的相关对象，如“自定义合同” |
