# 常见错误与排查指引
|问题表现|常见原因|排查建议|
|----|----|----|
|按钮未按预期隐藏|afterRender 事件未正确绑定，或绑定时机过早|检查 afterRender 是否绑定在正确组件上，并确保在页面完全渲染后执行控制逻辑|
|新增按钮始终显示|权限/配置接口返回数据未正确获取或解析|打印接口返回结果，确认enabled、relatedType 等字段是否正确，确保逻辑判断使用了正确的字段|
|删除按钮/编辑按钮显示异常|按钮唯一标识 buttonApiKey 或 scope 配置错误|确认组件唯一标识是否正确，尤其在相关列表或头部按钮组中，使用正确的 scope 和 buttonApiKey|
|页面报错或控制逻辑失效|访问未初始化的组件实例或 null 对象|使用 event.cmp.getComponent\(...\) 前检查组件是否存在，或在 afterRender 中执行逻辑|
|配置接口延迟导致按钮闪烁|接口异步返回未处理默认状态|对按钮设置初始状态（如隐藏），在接口返回后再调整可见性|
|权限控制未生效|后端权限配置返回不及时或数据缺失|在接口调用后，确保配置数据完整且无误，检查返回数据中的 enabled、defaultAdminRestricted 等字段|
|按钮状态错误显示|配置逻辑或权限判定有误，错误判断字段|检查配置逻辑，确保权限判定正确，特别是涉及角色和权限配置时，确保后台配置与前端逻辑匹配|
|按钮显示和行为不一致|没有正确处理界面更新，可能是事件绑定或组件更新错误|确保在 afterRender 事件中执行了所有动态控制，组件状态应在 DOM 渲染后更新|
|权限接口返回慢或失败|权限接口不稳定或网络问题|设置合理的超时处理机制，并在接口失败时提供备用策略，避免界面出现长时间未响应或无权限操作|
