# 方案介绍

## 方案概述

本方案通过在列表页面（EntityList）中进行组件级扩展实现。在数值字段级别使用条件样式扩展属性，根据字段取值动态设置显示颜色或样式。通过事件绑定和渲染逻辑，实现列表页中数值字段按数值区间高亮显示，使关键数据一目了然，提升用户在列表页的关注效率。

## 扩展组件

|终端|扩展对象|扩展页面|扩展区域|扩展组件|扩展功能|
|---|----|----|----|----|----|
|网页端/移动端|商机|一级列表页|数据列表|字段值|根据字段值所属的数据范围，动态以不同颜色进行区分展示|

## 功能设计

1.  **触发时机**

    在字段渲染前执行条件判断并应用相应样式。

2.  **条件判断逻辑**
    -   **获取字段值**

        遍历列表中每行记录，获取“商机金额”字段值。

    -   **数值区间匹配**

        根据预设规则判断字段所属区间，如下：

        金额 &gt; 1000 万：红色高亮

        金额在 500 万 - 1000 万：橙色高亮

        金额 &lt; 500 万：默认样式（黑色）
