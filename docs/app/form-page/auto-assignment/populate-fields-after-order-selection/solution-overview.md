# 方案介绍

## 方案概述

本方案通过在表单页面（EntityForm）中进行组件级扩展实现。在主表字段中监听“原始订单”字段的取值变化，当用户选择订单后，通过事件绑定触发自定义逻辑，调用接口获取原订单的主表和明细数据，并将结果自动回填至当前变更单表单中。

## 扩展组件

|终端|扩展对象|扩展页面|扩展区域|扩展组件|扩展功能|
|---|----|----|----|----|----|
|网页端/移动端|订单变更单|表单页|主表单|字段|在“原始订单”字段选择数据后，自动填充“客户名称”、“订单总金额”及对应的订单明细数据|

## 功能设计

**交互逻辑**：

1.  选择原始订单

    用户在订单变更单表单页中选择“原始订单”字段，系统监听字段变更事件。

2.  触发扩展逻辑

    触发 onChange 扩展逻辑，获取原订单的主表字段及明细信息。

3.  主表字段回填

    将原订单的客户名称、订单总金额主表字段填充到当前变更单的对应字段中。

4.  校验带出条件

    检测“是否带出明细”字段的状态，判断是否需要同步原订单的明细数据。

5.  用户操作与保存

    用户可在带出结果的基础上，对字段内容进行修改、补充或直接保存变更单数据。
