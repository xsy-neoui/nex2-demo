# 注意事项与最佳实践
1.  **按钮与字段绑定明确**

    仅在目标字段旁增加操作按钮，避免误绑定到其他字段或组件，确保逻辑只在指定字段触发。

2.  **数据校验与非空判断**

    在调用接口或弹窗前，先检查字段值是否为空或无效，避免空值导致的接口调用或回填异常。

3.  **事件逻辑封装**

    将复杂操作（如接口请求、回填逻辑、弹窗展示）封装成函数，提高可维护性和复用性。

4.  **异步操作与回调处理**

    AI 接口或弹窗操作通常是异步的，确保在回调函数中正确处理数据回填与关闭弹窗逻辑。

5.  **日志记录与调试**

    在关键节点（按钮点击、接口返回、回填）增加日志输出，便于开发调试和排查问题。

6.  **错误处理与用户提示**

    对接口失败、返回空数据或回填异常，应提供可读的提示信息，提升用户体验。

7.  **按钮样式与展示位置**

    按钮样式（颜色、圆角、大小）与位置要清晰可见，不遮挡原字段内容，保证用户操作体验。

8.  **跨端逻辑一致性**

    网页端和移动端可能存在组件实例或 API 调用差异，需确保逻辑在不同端保持一致。

9.  **接口返回值格式统一**

    AI 优化接口返回的字段名称和格式应与前端回填逻辑匹配，避免回填失败或数据错位。
