# 常见错误与排查指引
|问题表现|常见原因|排查建议|
|----|----|----|
|按钮显隐逻辑未生效|afterRender 未触发或放置位置错误|确认逻辑编写在 detailHeader.afterRender 内，且已启用扩展代码|
|获取不到详情数据|未正确调用 getDetailData\(\) 或页面实例未初始化|确认通过 props.getInstance\(\) 获取实例并调用 getDetailData\(\)|
|编辑按钮始终隐藏|条件判断逻辑有误或字段 API 名称不一致|检查字段 API 名称（如 owner\_\_c, status\_\_c, amount\_\_c）与系统配置是否一致|
|删除按钮显示异常|职能判断条件错误或角色编码不匹配|确认'DefaultAdmin' 与实际职能编码一致|
|控制逻辑执行时报错 Cannot read properties of undefined|调用组件前组件尚未加载|在逻辑中增加组件存在性判断，例如：if \(e.cmp.getComponent\)|
|按钮闪烁或加载后短暂错误显示|未设置初始状态或显隐逻辑执行过晚|在按钮定义中设置默认 visible: false，确保逻辑在渲染完成后执行|
|逻辑修改后仍不生效|扩展代码未重新启用或旧版本仍在运行|在 Nex Dev Tools 中确认扩展已保存并启用最新版本|
|多用户测试结果不一致|缓存未更新或用户信息未实时加载|重新登录后清理缓存，确保 ctx.user 数据实时更新|
|页面无响应或报错|缺少防空判断或数据类型错误|对业务字段加上空值校验与类型判断，防止执行异常|
