# 常见错误与排查指引
|问题表现|常见原因|排查建议|
|----|----|----|
|字段未高亮显示|未正确绑定事件或 apiKey 匹配错误|检查 beforeFieldRender 是否在 dataList 下正确配置，并确认字段 API 名称与对象定义一致|
|所有字段颜色一致|条件判断逻辑顺序错误或未使用else if|调整判断顺序，确保从高值到低值依次匹配，并为不满足条件的情况返回默认样式|
|页面渲染闪烁或报错|事件返回值格式不正确|确保返回对象格式为 \{ valueStyle: \{...\} \} 或 null，不要直接返回样式或 undefined|
|金额字段不变色|字段类型为文本或取值为空|确认字段类型为货币/数值类型，或在代码中显式使用 Number\(\) 转换|
|控制逻辑未生效|扩展代码未保存或未启用|确认已在 Nex Dev Tools 中保存并启用扩展代码|
|非目标字段被高亮|缺少apiKey 条件判断|在逻辑中使用 if \(e.data.apiKey == 'amount\_\_c'\) 限定作用范围|
|列表加载缓慢|逻辑中包含复杂计算或异步调用|简化条件判断逻辑，仅执行必要的数值比较和样式设置|
